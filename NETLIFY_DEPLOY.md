# Deploy LeadGapScan to Netlify

1. Upload this project to GitHub, GitLab, or Bitbucket.
2. In Netlify choose **Add new site > Import an existing project**.
3. Select the repository. Netlify will read `netlify.toml`, run `npm run build:netlify`, and use `.next` as the publish directory.
4. Deploy, then connect the LeadGapScan domain in Netlify's domain settings.

The current email dialog demonstrates the report gate and opens the printable report. Connect it to Netlify Forms or your email platform before treating submissions as saved leads. Add a privacy policy and update the consent language to match your follow-up.

Before launch, test the calculation, printing, mobile layout, analytics, form storage, and every conversion action. Replace starting benchmarks with verified sources or your own measured data whenever available.
